两部用代码画的音乐视频。每部有一份「什么都装在里面」的单片版，同时把源码也放进 `src/`，可以改、可以重渲。

## 1. 原版 · 水彩《我怀念的 · 留在右边的位置》

用代码逐帧绘制的水彩音乐视频，原创人物、原创故事，配孙燕姿《我怀念的》约 4:49 录音室版。

- 8 章、44 镜、289.07 秒，24 fps，1920×1080，共 6938 帧。
- p5.js + p5.brush：水彩晕染、干笔、墨线；人物是扁平的正 / 四分之三 / 侧 / 背，不做 3D 投影。
- 每帧由歌曲时间独立计算，纯函数，可乱序、并行、断点续渲；字幕用行级 LRC，不做逐字高亮。
- 故事：林夏想从共同回忆里找回周屿的回应，最后仍是不舍，却让开门、收起第二只杯子、把留给他的椅子推回桌下。

八章：留在右边的位置（0–46 s）→ 把问题藏进体面（46–74）→ 曾经被回应（74–116）→ 照顾变成告别（116–144）→ 同一段回忆的另一面（144–171）→ 那次他曾回头（171–197）→ 再看我一眼（197–258）→ 记忆留下，位置归还（258–289.07）。

**单片版**：[`原版-水彩MV-我怀念的.md`](原版-水彩MV-我怀念的.md) 把故事、八章表、技术、目录、跑法都写在一份读得完的文档里。

**源码**：[`src/watercolor/`](src/watercolor/) —— 原样保留的整棵工程（`studio.html`、`src/scenes/c01–c08.js`、`render.mjs`、`shots.json`、`audio.json`、`TIMELINE.md`、分镜与美术文档、`tools/`）。跑法见该目录下的 `README.md`。

## 2. 现在 · 星露谷风格《恋人》

李荣浩《恋人》4:36，**36 句歌词对应 36 个镜头**，加前奏、间奏、尾奏的 10 个空镜，一共 46 个镜头，覆盖 275.93 秒没有空档。

**单片版**：[`星露谷-MV-恋人.html`](星露谷-MV-恋人.html)，双击就能播，零依赖、不联网。

- 320×180 原生像素，最近邻放大 6 倍到 1920×1080，24 fps；抖动色带天空、山、农舍、巴士站，字幕走星露谷对话框。
- 两个主角是**从游戏本体解出来的原版行走图**：塞巴斯蒂安（他）与潘妮（她），16×32 一格、四方向 × 四帧，base64 内嵌在 HTML 里。
- 字幕画在放大之后的屏幕空间，推镜头时不变形、不糊。
- 单片版**无声**（音频 6.5 MB，且歌曲版权不在本仓），循环播放整片 4 分 36 秒。

故事：南方小镇的雨季，他在公交站遇见她；整个夏天他们坐同一班车、走同一条河堤；八月底她坐车走了，只留下一盘磁带。多年后他按下 PLAY，磁带卡住，画面真的倒回那个夏天。36 句歌词按 `恋人-李荣浩.lrc` 的时间戳逐句剪，第一句在 26.02 秒。

### 源码结构（`src/stardew/`）

```text
px.js       320×180 帧缓冲、调色板、Bayer 抖动、放大到屏幕
world.js    天空 / 山 / 地面 / 房子 / 栅栏 / 树 / 公交站 / 雨
sprite.js   两名角色的原版行走图（base64 内嵌）+ actor() 取帧
sets.js     14 个场景：农舍夜、录音机桌、磁带特写、公交站、公路、河堤、
            饭桌、鞋、空屋、窗、车进站、片名卡
scenes.js   36 句歌词 + 36 个时间戳 + 镜头表（每镜带推拉机位）
film.js     主循环：按时间找镜头 → 画场景 → 推镜 → 对话框字幕
tools/bundle-film.mjs   把上面 6 个文件打成单文件 HTML
tools/unpack.mjs        解包游戏 .xnb（原版行走图的来源）
```

```bash
# 需要静态服务器（ES module 不能 file:// 打开）
npx serve src/stardew        # 打开 http://localhost:3000

# 重新打包单文件
node src/stardew/tools/bundle-film.mjs src/stardew film-standalone.html
```

逐帧渲染成视频用的是外部渲染器（驱动 `window.render(t)` 逐帧截图再交给 ffmpeg），这部片子渲染了 6622 帧；字幕与对话框按 24 fps 逐帧重画，所以推镜头时不受影响。

### 星露谷的 .xnb 是怎么解开的

游戏 1.6 的内容是 XNB 包，头 `58 4E 42 77 05 81` = `XNB` + `w` + 版本 5 + `flags 0x81`，其中 `0x80` 是 **LZX 压缩**——不是 LZ4、不是 zlib，所以常规解包全部失败。用 `@xnb-js/core` 的 LZX 解压器解开，取 `content.export` 的 RGBA 像素再写成 PNG（见 `tools/unpack.mjs`）。
