## 1. 原版 · 水彩《我怀念的 · 留在右边的位置》

用代码逐帧绘制的水彩音乐视频，原创人物、原创故事，配孙燕姿《我怀念的》约 4:49 录音室版。

- 8 章、44 镜、289.07 秒，24 fps，1920×1080，共 6938 帧。
- p5.js + p5.brush：水彩晕染、干笔、墨线；人物是扁平的正 / 四分之三 / 侧 / 背，不做 3D 投影。
- 每帧由歌曲时间独立计算，纯函数，可乱序、并行、断点续渲；字幕用行级 LRC，不做逐字高亮。
- 故事：林夏想从共同回忆里找回周屿的回应，最后仍是不舍，却让开门、收起第二只杯子、把留给他的椅子推回桌下。

八章：留在右边的位置（0–46 s）→ 把问题藏进体面（46–74）→ 曾经被回应（74–116）→ 照顾变成告别（116–144）→ 同一段回忆的另一面（144–171）→ 那次他曾回头（171–197）→ 再看我一眼（197–258）→ 记忆留下，位置归还（258–289.07）。

原本散在仓库里的源码、分镜、时间数据、渲染脚本，已经收进归档文件；需要原文件时从历史取：

```powershell
git checkout 62de82f -- .     # 整棵旧树
git checkout 62de82f -- src/  # 只要源码
```

## 2. 现在 · 星露谷风格《恋人》

李荣浩《恋人》4:36，36 句歌词对应 36 个镜头（加空镜共 50 镜）。单文件 HTML，双击就能播。

- 320×180 原生像素，最近邻放大 6 倍到 1920×1080，24 fps；抖动色带天空、山、农舍、巴士站，字幕走星露谷对话框。
- 两个主角是**从游戏本体解出来的原版行走图**：塞巴斯蒂安（他）与潘妮（她），16×32 一格、四方向 × 四帧，base64 内嵌在 HTML 里。
- 字幕画在放大之后的屏幕空间，推镜头时不变形、不糊。
- 当前是 5 秒样片循环：他走进画 → 镜头缓推 → 末班车进站 → 车门打开。

地址栏参数换画面：

```text
?frame=sample   5 秒样片（默认）
?frame=farm     农舍·那年夏天
?frame=stop     镇口公交站
?frame=room     雨夜·空屋·录音机
?frame=cast     两个人下 / 右两个方向各四帧的走路表
```

单文件里没有音轨（6.5 MB 音频太重）；带声音的是工程目录里的 `sample.mp4`，剪自 2:29.82 起的副歌。

### 星露谷的 .xnb 是怎么解开的

游戏 1.6 的内容是 XNB 包，头 `58 4E 42 77 05 81` = `XNB` + `w` + 版本 5 + `flags 0x81`，其中 `0x80` 是 **LZX 压缩**——不是 LZ4、不是 zlib，所以常规解包全部失败。用 `@xnb-js/core` 的 LZX 解压器解开，取 `content.export` 的 RGBA 像素再写成 PNG。
